# SimplePhone - Универсальное приложение для аудиозвонков

Максимально простое веб-приложение для аудиозвонков, которое работает через интернет между любыми устройствами (iPhone, Android, PC, Mac).

## 🌟 Особенности

- ✅ **Работает через интернет** —无需 настройка сервера или роутера
- ✅ **Кроссплатформенность** — iOS (Safari), Android (Chrome), Windows, macOS, Linux
- ✅ **P2P соединение** — звук идет напрямую между собеседниками
- ✅ **Простая установка** — один HTML-файл, который можно залить на любой хостинг
- ✅ **Современный UI** — адаптивный дизайн, работает на мобильных устройствах
- ✅ **Бесплатно** — используется бесплатный облачный сервер PeerJS
- ✅ **Визуальный индикатор звука** — показывает когда собеседник говорит
- ✅ **Шумоподавление** — автоматическое подавление эха и шума
- ✅ **Надежное воспроизведение** — кнопка для включения звука если автоплей заблокирован
- ✅ **Звук входящего звонка** — уведомление о вызове

## 📋 Требования

- Современный браузер с поддержкой WebRTC:
  - Chrome/Edge (рекомендуется)
  - Safari 11+ (iOS/macOS)
  - Firefox
- Доступ к микрофону
- HTTPS соединение (обязательно для доступа к микрофону в браузере)

## 🚀 Быстрый старт

### Вариант 1: Локальный запуск (для тестирования)

1. Скачай файл `index.html`
2. Открой его в браузере
3. **Важно:** Для тестирования аудиозвонков на одном компьютере открой `index.html` в двух разных вкладках

### Вариант 2: Размещение в интернете (для реального использования)

#### Через Netlify Drop (самый простой способ)

1. Перейди на [netlify.com/drop](https://app.netlify.com/drop)
2. Перетащи файл `index.html` в область загрузки
3. Через несколько секунд получишь публичную ссылку вида `https://random-name.netlify.app`
4. Готово! Отправь ссылку другу

#### Через GitHub Pages

1. Создай репозиторий на GitHub
2. Загрузи файл `index.html` в репозиторий
3. Перейди в Settings → Pages
4. Выбери ветку (обычно `main`) и нажми Save
5. Через минуту получишь ссылку вида `https://username.github.io/repo-name`

#### Через Vercel

1. Установи Vercel CLI: `npm i -g vercel`
2. В папке с файлом выполни: `vercel`
3. Следуй инструкциям в терминале

## 📖 Как пользоваться

### Шаг 1: Получение своего ID

1. Открой приложение в браузере
2. Дождись загрузки (появится твой уникальный ID)
3. Нажми на ID чтобы скопировать его
4. Отправь этот ID другу (через мессенджер, SMS и т.д.)

### Шаг 2: Исходящий звонок

1. Введи ID друга в поле ввода
2. Нажми кнопку "Позвонить"
3. Разреши доступ к микрофону (если браузер спросит)
4. Жди пока собеседник примет звонок

### Шаг 3: Входящий звонок

1. Когда тебе звонят, появится уведомление
2. Нажми "Принять" чтобы начать разговор
3. Или "Отклонить" если не хочешь говорить

### Шаг 4: Во время разговора

- 🎤 **Выключить микрофон** — нажми на иконку микрофона
- 📊 **Индикатор звука** — показывает когда собеседник говорит
- ⏱️ **Таймер** — показывает длительность разговора
- 🔊 **Кнопка "Включить звук"** — появляется если звук не воспроизводится автоматически
- 📞 **Завершить звонок** — нажми красную кнопку

## 🔧 Техническая информация

### Архитектура

Приложение использует технологию **WebRTC** для передачи аудио напрямую между устройствами (P2P). Для установления соединения используется библиотека **PeerJS**, которая:

1. Подключается к бесплатному облачному серверу PeerJS для сигналинга
2. Помогает клиентам найти друг друга и обменяться данными соединения
3. Использует STUN-серверы Google для обхода NAT и файрволов

```
┌─────────────┐         ┌──────────────┐         ┌─────────────┐
│  Клиент A   │◄────────┤   PeerJS     │────────►│  Клиент B   │
│  (iPhone)   │  P2P    │   Сервер     │   P2P   │  (Android)  │
│             │  Аудио  │  (Сигналинг) │  Аудио  │             │
└─────────────┘         └──────────────┘         └─────────────┘
```

### Почему это работает через интернет?

WebRTC использует технологию **ICE (Interactive Connectivity Establishment)** для нахождения лучшего пути соединения:

1. **Прямое соединение** — если оба клиента в одной сети или имеют публичные IP
2. **STUN** — помогает определить публичный IP клиента за NAT
3. **TURN** — (резервный вариант) ретранслирует трафик если прямое соединение невозможно

PeerJS автоматически использует публичные STUN-серверы Google, поэтому соединение работает в большинстве случаев без дополнительной настройки.

### Безопасность

- **P2P шифрование** — WebRTC использует DTLS/SRTP для шифрования аудио
- **Временные ID** — ID генерируются случайно и действуют пока открыта страница
- **Нет хранения данных** — сервер PeerJS только пересылает сигналы, не сохраняет аудио

## 🐛 Возможные проблемы и решения

### Проблема: "Разрешите доступ к микрофону"

**Причина:** Браузер блокирует доступ к микрофону без HTTPS или если пользователь запретил доступ.

**Решение:**
1. Убедись что сайт открывается по HTTPS (зеленый замок)
2. Проверь настройки браузера: Разрешения → Микрофон
3. На iOS: Настройки → Safari → Микрофон

### Проблема: "Собеседник не найден"

**Причина:** ID собеседника введен неверно или его страница закрыта.

**Решение:**
1. Проверь правильность ID (скопируй и вставь)
2. Убедись что собеседник открыл приложение и его ID загружен
3. Если собеседник перезагрузил страницу — его ID изменился

### Проблема: Нет звука у собеседника

**Причина:** Проблемы с микрофоном или браузером.

**Решение:**
1. Проверь что микрофон работает в других приложениях
2. Перезагрузи страницу и попробуй снова
3. На iOS: убедись что сайт открыт в Safari (не в Chrome)
4. Проверь громкость на устройстве

### Проблема: Соединение устанавливается, но нет звука

**Причина:** Браузер блокирует автовоспроизведение аудио.

**Решение:**
1. Нажми в любом месте страницы после соединения
2. Перезагрузи страницу и попробуй снова
3. Используй Chrome/Edge вместо Safari (лучше поддерживает WebRTC)

### Проблема: Работает на Wi-Fi, но не на 4G

**Причина:** Некоторые мобильные операторы блокируют P2P соединения.

**Решение:**
1. Попробуй другой браузер (Chrome вместо Safari)
2. Попробуй другую сеть (Wi-Fi вместо 4G)
3. Свяжись с оператором (редкий случай)

### Проблема: Звук с эхом или шумом

**Причина:** Акустическая обратная связь или плохой микрофон.

**Решение:**
1. Используй наушники
2. Включи шумоподавление в настройках микрофона устройства
3. Отойди от колонок/динамиков

## 📱 Особенности мобильных устройств

### iOS (iPhone/iPad)

- **Только Safari:** Chrome на iOS не поддерживает WebRTC так хорошо как Safari
- **Автоблокировка:** Убедись что экран не гаснет во время разговора
- **Фоновый режим:** При переключении на другое приложение звук может пропасть

### Android

- **Рекомендуется Chrome:** Лучшая поддержка WebRTC
- **Разрешения:** При первом запуске разрешите доступ к микрофону
- **Энергосбережение:** Отключите энергосбережение для браузера
