# 🔍 Проверка подключения SimplePhone

## Шаг 1: Проверь загрузку ID

Открой `index.html` и посмотри:

### ✅ Если ID загружен (показывается цифры/буквы)
**Отлично!** Подключение к серверу работает. Можно звонить.

### ❌ Если "Загрузка..." или ошибка
**Проблема с подключением.** Выполни следующие шаги:

---

## Шаг 2: Проверь консоль браузера

1. Открой `index.html`
2. Нажми **F12** (или Ctrl+Shift+I)
3. Перейди на вкладку **Console**
4. Посмотри что написано

### Что искать в консоли:

#### ✅ Хорошо:
```
✅ Connected to PeerJS with ID: abc123xyz
✅ Server: 0.peerjs.com:443
```

#### ❌ Плохо:
```
❌ PeerJS error: ...
❌ Connection error
```

---

## Шаг 3: Проверь сетевые запросы

1. В консоли (F12) перейди на вкладку **Network**
2. Перезагрузи страницу (F5)
3. Ищи запросы к `peerjs.com`

### Должен быть виден:
- Запрос к `wss://0.peerjs.com` (WebSocket соединение)
- Статус: **101 Switching Protocols**

### Если ошибка:
- Статус: **404**, **403**, **500** — проблема с сервером
- Статус: **ERR_CONNECTION_REFUSED** — проблема с интернетом или блокировка

---

## Шаг 4: Проверь диагностику

1. Открой `diagnostic.html`
2. Запусти все тесты
3. Посмотри результаты

### Все тесты должны быть зелеными:
- ✅ Поддержка WebSocket
- ✅ Поддержка WebRTC
- ✅ Доступ к микрофону
- ✅ HTTPS соединение
- ✅ Web Audio API
- ✅ PeerJS серверы (хотя бы один)

---

## Шаг 5: Попробуй другой хостинг

Если GitHub Pages не работает:

### Netlify Drop (рекомендуется)
1. Перейди на https://app.netlify.com/drop
2. Перетащи папку с файлами
3. Получи ссылку вида `https://xxxxx.netlify.app`
4. Открой `https://xxxxx.netlify.app/diagnostic.html`
5. Проверь что все работает

### Vercel
1. Установи: `npm i -g vercel`
2. В папке с файлами: `vercel`
3. Следуй инструкциям

### Локальный сервер
```bash
# Установи Python (если нет)
# Запусти локальный сервер
python -m http.server 8000

# Открой в браузере
http://localhost:8000/index.html
```

## Шаг 6: Проверь браузер

### iOS (iPhone/iPad)
- ✅ Используй **Safari** (не Chrome!)
- ✅ Разреши доступ к микрофону: Настройки → Safari → Микрофон
- ✅ Отключи "Блокировать все файлы cookie"

### Android
- ✅ Используй **Chrome**
- ✅ Разреши разрешения при первом запуске
- ✅ Отключи экономию трафика в настройках Chrome

### Windows/Mac
- ✅ Chrome или Edge (лучше всего)
- ✅ Firefox (может работать хуже)
- ✅ Safari на Mac (может работать хуже)

---

## Шаг 7: Проверь интернет

### Тест подключения
В консоли (F12 → Console) выполни:

```javascript
// Тест 1: Проверь интернет
fetch('https://www.google.com')
  .then(() => console.log('✅ Интернет работает'))
  .catch(() => console.log('❌ Нет интернета'));

// Тест 2: Проверь PeerJS
fetch('https://0.peerjs.com')
  .then(() => console.log('✅ PeerJS доступен'))
  .catch(() => console.log('❌ PeerJS недоступен'));

// Тест 3: Проверь WebSocket
const ws = new WebSocket('wss://0.peerjs.com');
ws.onopen = () => console.log('✅ WebSocket работает');
ws.onerror = () => console.log('❌ WebSocket ошибка');
```

## Общие решения

### Проблема: "Соединение с сервером потеряно"

**Решение 1:** Нажми кнопку "🔄 Переподключиться к серверу"

**Решение 2:** Перезагрузи страницу (F5)

**Решение 3:** Подожди 1-2 минуты (сервер может быть перегружен)

**Решение 4:** Попробуй другой браузер

**Решение 5:** Смени хостинг (Netlify вместо GitHub Pages)

### Проблема: ID не загружается

**Проверь:**
1. Открыт ли сайт по HTTPS? (должен быть зеленый замок)
2. Есть ли интернет соединение?
3. Не блокирует ли антивирус/фаервол?
4. Не блокирует ли корпоративный прокси?

---

## Если ничего не помогло

Собери информацию:

1. **Скриншот консоли** (F12 → Console)
2. **Скриншот Network** (F12 → Network)
3. **Скриншот диагностики** (diagnostic.html)
4. **Информация о системе:**
   - Устройство: iPhone/Android/PC/Mac
   - Браузер: Chrome/Safari/Firefox/Edge + версия
   - ОС: iOS/Android/Windows/macOS + версия
   - Хостинг: GitHub Pages/Netlify/Vercel/другой

Создай Issue на GitHub с этой информацией.
